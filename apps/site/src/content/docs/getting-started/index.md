---
title: 开始之前
description: 了解小组、仓库、任务包和贯穿八周的工作方式。
---

课程以三人固定小组完成。八周内持续维护同一套自主软件开发与测试系统，不为每周实验新建彼此无关的项目。

## 开始前确认

- 三名成员分别使用自己的 Git 身份加入小组仓库；
- 本地具备课程指定的 Git、容器和开发工具；
- 小组能够使用课程提供的 AI Coding 平台或模型调用入口；
- 已阅读统一任务输入、系统启动、输出仓库和日志协议；
- 所有成员理解最终目标是构建开发系统，而不是手工完成公开应用。

## 贯穿仓库

建议将系统实现、中间表示 Schema、工具、测试和文档放入同一仓库。每周在上周版本上增量实现，并使用 tag 或提交记录标记候选版本。

公开任务可以用于调试系统，但不得把任务答案、应用模板或专用分支硬编码进系统。Week 8 将使用冻结版本处理此前未见的任务。

:::caution[不要提交秘密]
不得提交账号密码、API Key、访问令牌、私有任务、隐藏测试或其他小组材料。正式环境通过安全方式注入模型凭据。
:::
