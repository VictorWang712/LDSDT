课程不持续监控小组的开发过程。每周以冻结的 Git commit、统一入口、机器可读产物和可复现实验结果检查本周能力。

## 每周提交

每个里程碑至少提交：

- 已推送的候选 commit；
- 本周模块实现与对应测试；
- 规定格式的中间产物；
- 一次完整运行的结构化日志；
- 英文 README 中的运行方法、设计选择和已知限制。

## 端到端提交

系统需要接受任务包并将生成仓库与执行证据写到指定位置。最终命令和目录将在协议稳定后发布，概念形式如下：

```bash
course-agent run \
  --task ./task-package \
  --output ./generated-project \
  --log ./execution-log
```

教学组在干净环境中复现运行，检查输出仓库的安装、构建、启动、功能、鲁棒性和工程质量。Week 8 使用截止日前冻结的系统 commit；运行期间不允许人工修改生成代码。
