本周实现软件构造能力。系统需要把设计产物转换为任务计划，使用开发工具逐步修改仓库，并以真实构建和运行反馈约束代码生成。

## 需要实现

1. 根据 Requirement IR 和设计产物拆分实现任务，维护完成状态和依赖；
2. 初始化符合课程技术栈的项目，管理依赖和配置；
3. 读取相关仓库上下文，创建、修改和删除文件；
4. 执行格式化、静态检查、构建、启动和必要的探针；
5. 使用 Git commit、补丁或等价机制保存可回退检查点；
6. 将实现文件与需求、组件或接口建立可查询联系；
7. 失败时保留命令输出和未完成状态，不伪造成功。

本周只要求完整实现一个纵向功能切片：它应贯穿需要的界面/API/数据层，而不是生成大量互不连通的代码骨架。

## 本周交付

- 实现模块及任务状态表示；
- 从给定需求与设计产物生成的切片仓库；
- 安装、构建、启动和健康检查说明；
- 文件变更、工具执行和 Git 检查点日志；
- 模块测试和已知失败说明。

## 如何检查

教学组在空白输出目录中运行实现模块，随后只依据生成仓库声明的方法安装、构建和启动，并执行公开切片测试。还会检查：

- 代码是否真实实现设计契约，而非仅生成占位文件；
- 构建失败能否进入系统反馈，而不是留给人工收尾；
- 多次修改是否保持仓库结构与已有功能；
- 关键变更是否具备来源、任务和检查点证据；
- 输出是否包含硬编码任务答案或不允许的预制应用。
