本课程鼓励广泛使用大语言模型、AI Coding 平台和 Agent 框架。学术诚信的重点不是禁止 AI，而是确保系统、证据和个人贡献真实。

## 允许与鼓励

- 使用 AI 讨论设计、生成代码和测试、分析错误、重构与撰写文档；
- 比较不同 Agent 组织、提示、IR、测试或修复策略；
- 使用合法开源库和公开资料，并按许可证和课程要求注明来源；
- 记录模型、平台、关键配置和执行证据。

## 不允许

- 将其他小组或往届项目作为本组系统冒充提交；
- 伪造 Agent 运行、测试通过、工具调用、Git 贡献或人工干预记录；
- 针对公开任务硬编码答案，或尝试获取、推断和泄露私有任务及隐藏测试；
- 在生成仓库中植入针对评测 Agent 的提示注入或规避命令；
- 提交无权使用的代码、数据、凭据或受限制模型输出。

## 责任与理解

小组对 AI 生成的一切提交内容负责。每名成员都必须能够解释自己负责的模块、关键中间表示、失败恢复机制和最终结果。无法解释的重要实现可能触发个人核验，并影响个人成绩。
