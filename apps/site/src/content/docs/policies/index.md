## 基本原则

- 课程以三人固定小组完成，每名成员使用独立 Git 身份并承担可识别职责；
- 只能在分配的账号、额度、仓库和评测环境内开展实验；
- 不访问、复制或干扰其他小组的系统、日志、任务和评测结果；
- 不将账号、密钥、私有任务、隐藏测试和受限数据提交到公开仓库；
- 公开任务允许反复改进，私有评测必须使用冻结系统并遵守人工干预限制；
- 平台故障、重跑、迟交和成绩复核按正式发布流程处理。

## 数据与后续研究

课程正常教学所需的代码、测试结果和贡献记录用于验收。若课程组希望将匿名轨迹、问卷、访谈或项目用于科研，将另行说明用途并获取授权；拒绝参与研究不影响课程成绩。优秀项目进入课题组继续开发时，贡献、开源许可和论文署名将重新确认。
