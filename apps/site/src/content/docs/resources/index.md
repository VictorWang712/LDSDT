正式实验将按版本集中发布以下资源：

- **Starter Kit**：模型适配、文件与 Shell 工具、工作区、超时与事件日志；
- **System Protocol**：统一 CLI、任务输入、输出仓库与运行结果；
- **Schemas**：Requirement IR、设计产物、测试结果和执行事件的最低要求；
- **Weekly Fixtures**：需求样例、参考仓库、缺陷变体与公开检查器；
- **End-to-End Tasks**：公开任务包、示例与公开测试；
- **Evaluation Environment**：容器镜像、资源限制和本地复现说明；
- **References**：Agentic Software Engineering、需求工程、架构、测试和调试资料。

资源与讲义使用相同版本号。任务或协议更新时将提供变更记录和兼容性说明，避免学生系统依赖未声明行为。

:::note[发布状态]
当前页面定义资源清单；下载链接将在平台、技术栈和统一协议确定后补充。
:::
