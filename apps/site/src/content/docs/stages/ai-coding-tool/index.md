本阶段要求学生调用自己在第一阶段部署的模型服务，构建一个面向软件开发任务的 AI Coding 工具。

工具形态不作限定，可以是：

- Visual Studio Code 插件；
- Web 应用；
- 独立桌面应用；
- 命令行工具；
- 其他满足接口要求的交互形式。

## 关键约束

最终工具需要预留统一的能力调用接口，使教学方能够自动验证功能，并证明关键能力来自第一阶段交付的模型服务。
