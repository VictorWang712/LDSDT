工具设计是课程实验的第二阶段。学生需要调用自己在第一阶段部署的模型服务，设计并实现一个面向软件开发任务的 AI Coding 工具。

工具形态不作限定，可以是 Visual Studio Code 插件、Web 应用、独立桌面应用、命令行工具，或其他满足课程接口要求的交互形式。
